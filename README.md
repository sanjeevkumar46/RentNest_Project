# 🏨 Room Rental Management System

A **PHP & MySQL based Room Rental Management System** that allows users to browse available rooms, book them online, and manage their bookings. The system also provides separate dashboards for **Admin**, **Owner**, and **User** to efficiently manage rooms, bookings, and users.

---

## 📌 Project Overview

The Room Rental Management System is a web-based application developed using **PHP**, **MySQL**, **HTML**, **CSS**, and **XAMPP**. It simplifies the process of listing rental rooms, making bookings, and managing room availability.

The application supports three types of users:

- **Admin**
- **Owner**
- **User**

Each user has different permissions and functionalities.

## ⚙️ Installation

1. Install **XAMPP**.
2. Copy the project folder into the `htdocs` directory.
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Create a new MySQL database.
5. Import the provided SQL file into the database.
6. Update database credentials in:

```
config/db.php
```

7. Open the browser and run:

```
http://localhost/Room-Rental-Management-System/
```
